# Glosario PromoHunt

- **API REST** — Comunicación HTTP entre frontend y backend (`/api/...`)
- **Flask** — Framework Python del backend
- **PostgreSQL** — Base de datos relacional
- **psycopg2** — Driver Python ↔ PostgreSQL
- **React** — Biblioteca del frontend
- **Vite** — Bundler / dev server del frontend
- **SERIAL** — Auto-incremento en PostgreSQL
- **Sesión** — Auth por cookie (`promohunt_session`)
